Advisor

The advisor translates your entities and queries into every candidate framework, measures the generated code against the benchmark database, and solves an ILP model over the measured costs to recommend a framework — or a combination — for the workload. It needs the native ILP solver, so it runs only in the containerized deployment.

If the limits admit no solution, the run does not come back with an empty result: it fails, and the message carries the solver's status code.

5. Run

A run is not a translation. For every query and every candidate framework it translates the workload, compiles the generated code with Roslyn, executes it against the benchmark database to measure time and allocations, and only then solves the ILP model. Expect minutes rather than seconds, and one measurement per query and framework.

Result

Every candidate measured for a query is listed, fastest first, with the one the model assigned marked. The assignment is not always the fastest row: the memory limit and the cap on how many frameworks may be selected are part of the model, and the totals below count the assigned rows only.
