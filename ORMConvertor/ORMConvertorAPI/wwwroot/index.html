ORMConvertor

A research tool that translates entities, mappings and queries between .NET ORM frameworks — Dapper, NHibernate and EF Core — through a framework-agnostic intermediate representation, and recommends the best framework for a query workload from real benchmark measurements.

Translation

Upload or paste entity classes, mappings and queries, pick a source and a target framework, and read the generated artifacts together with the structured diagnostic records of the conversion.

Open the translator

Advisor

Give the advisor your entities and a query workload with weights, and it selects the best framework — or combination of frameworks — by measuring the generated code, then solving an ILP model over the measured costs.

How it works

Every translation runs the same pipeline: a framework-specific parser reads the source artifacts into the intermediate representation; an optional completion phase fills mapping facts the source never stated from the database catalog, when a connection is configured on the server; and a framework-specific builder generates the target artifacts. Whatever cannot be carried over — and whatever was filled in by a convention or by the catalog — is reported as a structured record next to the artifacts, never silently.

ORMConvertor — a research prototype. The advisor requires the native ILP solver and runs only in the containerized deployment.
