# The differential matrix (decision 089). One section per query; the pairs of the
# criterion are this query's source framework against each of the other five, so six
# queries make the thirty pairs F13 asks for.
#
# Read by both suites from this one file, beside the schema script - the mechanism
# decision 076 set up so that the schema stays one. The format is deliberately poorer
# than JSON: two parsers in two languages have to agree about it, and a line of
# "key = value" cannot be read two ways.
#
#   source          the framework the query is written in. Its own run is what fixes the
#                   canonical result; every other framework is a pair against it.
#   units           the input files of a conversion, entity units first, query unit last.
#                   A MyBatis mapper is both at once (decision 081), so it appears once.
#   fields          the fields of a result row, in the order the canonical form states
#                   them. A by-name target reads these names off the entity, a positional
#                   one reads by index; both give the same ordered values.
#   shape           entity   - every target returns instances of the generated entity
#                   projection - the targets that project return tuples, and HQL and JPQL
#                               return them positionally
#   ordered         whether the query carries an ordering instruction. When it does not,
#                   both sides sort by the rendered line before comparing.
#   decimalScale    decimal places an exact decimal is rounded to (default 6)
#   floatDigits     significant digits of an approximate number (default 12)
#   arguments       values of the query's parameters, name:type=value (decision 083)
#   mutations       the wrong translations this query can carry (decision 089), of
#                   filter, operator, ordering, rowCount, projection. Stated rather than
#                   discovered, so that a mutation which stops reaching the artifact is a
#                   failure instead of a case that quietly stops running.
