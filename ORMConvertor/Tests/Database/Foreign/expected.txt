# The artifacts of this directory hold the path of a foreign artifact (decision 172): each
# one is written by hand to end at a stated level with a stated outcome, and the test of
# the path in the suite that owns its target asserts exactly that row - never a failure.
# One artifact per target reaches the fourth level and agrees with the measure; the others
# stop at one level each, so that the path is seen refusing at every level once.
#
#   reached   the highest level passed: 0 the language does not read a unit, 1 read,
#             2 compiled, 3 accepted by the framework, 4 ran
#   outcome   unreadable, not compiled, not accepted, failed, differs, agrees, accepted
